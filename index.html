锁定版本 vuepress@1.9.10 · Vue 2 + Webpack 4 经典架构实测

01. 专属标注与元数据 →

01. 仅内置三类提示框 (缺 info 与 GFM)

开箱仅支持 ::: tip / warning / danger / details，原生不支持 ::: info，亦不识别 GitHub > [!NOTE] 警报。

02. Webpack 4 无法打包现代 Mermaid

内置 Webpack 4 遇到现代 ES2022 语法直接崩溃，只能锁定最后一代带 UMD 产物的 mermaid@10.9.8 静态脚本注入。

03. extendMarkdown 扩展 KaTeX

社区旧版公式插件多已年久失修，通过在 config.js 的 extendMarkdown 编写 30 行规则直连 katex@0.19.1 构建期渲染。

04. OpenSSL 3 时代包袱与自动组件注册

在 Node 18/20/22 下必须传入 NODE_OPTIONS=--openssl-legacy-provider；但拥有独特的 .vuepress/components 自动全局注册约定。
